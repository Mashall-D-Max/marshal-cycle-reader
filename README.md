# Цикл Маршала — онлайн-читалка

Публичная копия утверждённой HTML-читалки. Литературные исходники, сюжетные планы и канон в этот репозиторий не входят.

- GitHub Pages: https://mashall-d-max.github.io/marshal-cycle-reader/
- Ветка публикации: `main`.
- `index.html` создаётся основным сборщиком проекта и вручную не редактируется.
- После изменения литературных глав основной проект запускает `Сюжет/РАНОБЭ_V2_HTML/tools/publish_github_reader.ps1`, который фиксирует только обновлённый `index.html`, выполняет `git push origin main` и подтверждает совпадение номера последней главы и SHA-256 всего нормализованного HTML в интернете.
